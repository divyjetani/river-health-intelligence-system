This is River health intelligence system.

In this project we made a web app that will take input of image and textual data and give it to 3 different ML models to predict the health of specific river.
here are 3 models we used:
  1. Gradient boosting regressor
  2. YoloV8n

and after that it will combine all models weighted output into a one health score between 0 to 100. higher score -> higher pollution
